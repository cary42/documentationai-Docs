## What Useful Links does

Useful Links is a short list of web links that people can open from the **Useful Links** menu item in the Campium mobile app. Each link has a name, a web address, and an optional description. Camps use it for things like packing lists, external forms, or partner websites. For how the list looks in the app, see [Mobile App](/mobile-app).

<Callout kind="info" collapsed="false">
  **Admin → Useful Links** is not available on every account, and it shows only for users with the **Administrator** role. If you do not see it and want it, contact Campium support.
</Callout>

## Show the list in the app

The app shows **Useful Links** only when **Display Useful Links menu item** is on. You find that toggle in **Admin → Mobile App Settings** or in **Admin → Site Settings → Mobile App**. See [Mobile App Settings](/mobile-app-settings).

## What is on the page

The page lists your links in a table with these columns:

- **Link Name**
- **URL**
- **Description**

Each row has a menu with **Edit** and **Delete**. If you have no links yet, the page shows **No Useful Links**.

## Add a link

<Steps>
  <Step title="Start a new link" icon="plus-circle" title-type="p">
    Click **Add New Useful Links** at the top of the page. The **New Useful Link** window opens.
  </Step>

  <Step title="Fill in the link" icon="link" title-type="p">
    Enter a **Link Name** and the **URL**. Add a **Description** if you want one.
  </Step>

  <Step title="Save" icon="check-circle" title-type="p">
    Click **Save**. The page reloads with your new link in the table.
  </Step>
</Steps>

**Link Name** and **URL** are required. Each link needs its own name; if the name is already taken, you see **A link with that link name already exists.**

## Edit or delete a link

- **Edit** - open the row menu and choose **Edit**. The **Edit Useful Link** window opens with the same fields. Change what you need and click **Save**.
- **Delete** - open the row menu and choose **Delete**, then confirm. The row is removed from the table.
