---
title: "Ask when picked"
description: "Require profile answers right under a session when a family selects it, then follow up on Missing Answers."
---

**Ask when picked** lets you attach required profile questions to a session or add-on. When a family ticks that item on the registration form, those questions appear under it. Use this for details that only matter for that choice, such as a T-shirt size for a specific program.

## Set questions on a session

1. Open **Seasons**, then open the season (or **Guided setup**).
2. On the **Sessions** step, open **Edit session** (or **Add session**).
3. Find **Ask when picked**. Helper text: **Families answer these right under this item when they pick it, for example a T-shirt size. Each one is required.**
4. Add the profile fields families must answer when they select this session.
5. When no fields are linked, the summary reads **No required questions**.
6. Save the session.

You can set the same block when you add a new session. The fields are always required once they are linked.

## What families see

On the sessions selection page, after they tick the session, the linked questions appear under that item. They must answer them before they can continue.

If they registered earlier and still owe an answer (for example the question was added later, or they never completed it), Parent Home can show:

- **We need 1 more answer from you** / **We need N more answers from you**
- **Answer 1 question** / **Answer N questions**

The modal lists each missing field (with **For** the session name when needed). Families choose an answer, then **Save** (or **Cancel**).

## Missing Answers report

When people on a session still have not answered a linked field, Season Setup and related session screens can show a link such as **1 camper on this session has not answered Grade** (or **N campers…**), naming the field.

That opens a **Missing Answers** report titled with the field and session (for example **Missing Answers - Grade - Week 1**) with columns **Camper**, **Guardian 1**, **Email**, and **Cell Phone**. Use **Send Text** or **Send Email** to remind those families.
