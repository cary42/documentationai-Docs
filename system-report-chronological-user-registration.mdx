## What this report shows

Use the Chronological User Registration report to see a season's registrations in the order they came in. Each person appears once, with what they signed up for and when.

Because each person appears once, the report also answers quick "how many" questions about a season. Pick a profile field and one answer, and the record count under the table is your number. For example: how many 5th graders are registered this summer, how many campers are in Cabin 4, or how many people chose the bus.

<Callout kind="info">

Use this report when you want a timeline of sign-ups, such as watching opening day, or a fast count of people in a season who share one profile answer.

</Callout>

## Where to find it

<Steps>

<Step title="Open System Reports" icon="folder">

- Sign in to your Campium admin site.
- In the main navigation, go to **Reports**, then **System Reports**.

</Step>

<Step title="Open Chronological User Registration" icon="list">

- Select **Chronological User Registration**.
- The report opens for your current season. The back arrow next to the title returns you to System Reports.

</Step>

</Steps>

## Choose a season

The season picker at the top of the page controls which registrations appear. Pick the season you want and the report reloads for it. The report shows one season at a time.

<Callout kind="info">

If the report looks empty, check that the right season is selected and that registration for that season has opened.

</Callout>

## Count people with one profile answer (for example, 5th graders)

The **Filter by profile field** control is the first thing on the row above the table.

<Steps>

<Step title="Pick a profile field" icon="filter">

- Click **Filter by profile field** and start typing, for example **Grade**.
- Fields are grouped by person: the registrant's own fields first, then **Family**, **Guardian 1**, **Guardian 2**, and **Staff**.

</Step>

<Step title="Pick the answer" icon="check">

- For a multiple-choice field, a second list opens with that field's answers. Pick one, for example **5th**.
- For a text field, type part of the answer in the **Contains...** box and press Enter.
- For a date field, pick the day.
- The report reloads right away. There is no Apply button.

</Step>

<Step title="Read the count" icon="hash">

- The record count under the table (for example **42 records**) is how many people in this season have that answer.
- For a multi-select field, a person counts when their answers include the one you picked.

</Step>

<Step title="Clear the filter" icon="x">

- Click **Clear** next to the filter to show everyone again.

</Step>

</Steps>

<Callout kind="tip">

The filter stays on when you switch seasons, so you can compare the same answer across seasons, such as 5th graders this summer versus last summer. The page address includes the filter, so you can bookmark it or send the link to a colleague.

</Callout>

To count everyone at once, broken down by every answer (all grades side by side), use the [Matrix Report](/matrix) or the profile field breakdown on the [Revenue Summary](/revenue-summary).

## Filter by status

The **All**, **Pending**, **Active**, and **Inactive** buttons next to the profile filter narrow the table to people in that status. Each button can show a count badge. While a status is picked, the count beside the buttons reads **Showing N of M**.

The status buttons work together with the profile filter. For example, pick **Grade** and **5th**, then **Active**, to count active 5th graders.

## Filter by New or Returning

Use **All**, **New**, and **Returning** to limit the table to first-time or returning registrations for the season you are viewing. Each toggle shows a count badge.

- **New** means the person has no earlier-season registration that counts toward retention (cancelled, pending, and fee-only lines do not count).
- **Returning** means they have an active registration in an earlier season.

These toggles work with the status buttons and the profile filter.

## Columns you will see

- **Name** (your camp's label for registrants, such as Camper) - Click the name to open the profile.
- **# Seasons** - How many seasons the person has registered for, so you can tell returning families from first-timers.
- **New / Returning** - **New** or **Returning** for this season, using the same rule as the toggles above.
- **Season** - The season the registration belongs to.
- **Sessions** (your camp's label) - The sessions or products in that registration.
- **Email** - The family's primary email. For staff, their own email.
- **User Status** - **Active**, **Pending**, **Inactive**, and so on, shown as a colored label.
- **Date** - When the registration was created, down to the minute.

Some camps also see **Location** or a second email column.

## Add profile fields as columns

<Steps>

<Step title="Open Display columns" icon="settings">

- Click **Display columns** at the top right of the Registrations panel.

</Step>

<Step title="Check the fields you want" icon="edit">

- Type in the filter box to find a field, then check it. The count next to the box shows how many you picked.

</Step>

<Step title="Save" icon="check-circle">

- Click **Save columns**. The page reloads with your fields as extra columns. Click **Cancel** to close the panel without saving.

</Step>

</Steps>

Your column choices are remembered for next time.

<Callout kind="tip">

You do not need a field as a column to filter by it. Add it as a column only when you want to see everyone's answer.

</Callout>

## Sort, search, and export

- Click a column header to sort. Click **Date** to put the newest or oldest registrations first.
- Type in the table's **Filter** box to search the rows on the page.
- Use **Export** for Copy, Excel, CSV, PDF, or Print. The export matches what you see, including your profile and status filters.

## Common questions

<ExpandableGroup>

<Expandable title="How many 5th graders (or campers in Cabin 4) are registered this season?" default-open="false">

1. Open **Reports**, then **System Reports**, then **Chronological User Registration**.
2. Pick the season at the top.
3. In **Filter by profile field**, pick **Grade** (or **Cabin**), then pick **5th** (or **4**).
4. Read the record count under the table.

Add **Active** from the status buttons if you only want active registrations.

</Expandable>

<Expandable title="Why is the report showing no registrations?" default-open="false">

- Confirm the right season is selected.
- If a profile filter is on, the panel says **No registrations match this filter.** Click **Clear** or pick a different answer.
- Make sure registration for that season has opened.

</Expandable>

<Expandable title="Can I filter by two profile fields at once?" default-open="false">

This report filters by one field and one answer. For more than one condition, build a [custom report](/custom-reports) with filters, or use the [Matrix Report](/matrix) to count across two fields.

</Expandable>

<Expandable title="What is the difference between this report and the Waitlist report?" default-open="false">

This report shows completed registrations in the order they were created. The [Waitlist](/waitlist) report shows people who asked for a spot in a full session and are not enrolled yet.

</Expandable>

</ExpandableGroup>
