## Cancellation fees guide for camp staff

Use **Cancellation Fees** to create a dedicated fee session in a season, then add that same session whenever you charge a cancellation fee. The panel is on the **Sessions** step in [Guided Season Setup](/guided-season-setup).

<Callout kind="alert">

Cancellation fees are **not** applied automatically when a registration is cancelled. Creating a cancellation fee here only defines the fee session. To charge it, add the fee to the family from their profile's **Sales** tab. For the full cancellation workflow, see [Withdraw a camper or cancel a registration](/withdraw-a-camper).

</Callout>

---

## Who should use this

Use this guide if you:

- manage sessions in the admin
- handle cancellations and fee adjustments
- need a consistent way to track cancellation-fee charges

---

## Where to find Cancellation Fees

<Steps>
  <Step title="Open the season" icon="home">

In the left menu, open **Seasons**.

Click the name of the season you are managing. Season setup opens on the **Sessions** step.

  </Step>
  <Step title="Find the Cancellation Fees panel" icon="settings">

Find the **Cancellation Fees** button at the top of the **Sessions** card, next to **Table** and **Calendar**.

Select it to expand the panel. The panel repeats the reminder: **Cancellation fees are not applied automatically when a registration is cancelled. You add the fee via a profile's sales tab.**

  </Step>
</Steps>

<Callout kind="info">

If you do not see **Cancellation Fees**, contact support.

</Callout>

---

## Create a cancellation fee

In the expanded **Cancellation Fees** panel, enter:

- **Name**: clear session name (placeholder: `Cancellation Fee`)
- **Amount**: fee amount greater than 0 (example: `150.00`)
- **Description**: short explanation shown with the fee (placeholder: `Fee charged when a registration is cancelled`)

All three fields are required.

Then select **Save Cancellation Fee**.

### What happens after save

- The fee appears in **Existing Cancellation Fees**.
- It is saved to the season you are setting up.
- The amount becomes both the price and the minimum deposit of the fee session, so the family owes the full fee.
- Discounts do not apply to the fee session.

---

## Apply a cancellation fee to a family

Creating the fee does not charge anyone, and neither does cancelling a registration. When you decide to charge a cancellation fee, add it yourself:

- Open the family's profile.
- Go to the **Sales** tab.
- Select **Add Session** (the button uses your camp's term for sessions) and add the cancellation-fee session you created.

You decide when a cancellation fee applies, instead of Campium charging it on every cancellation.

---

## Edit an existing cancellation fee

<Steps>
  <Step title="Choose the fee to update" icon="edit">

In **Existing Cancellation Fees**, find the row you want.

Select **Edit**.

  </Step>
  <Step title="Update the details" icon="settings">

Update name, amount, or description.

Select **Save Cancellation Fee** again.

  </Step>
</Steps>

Use **Cancel Edit** to leave edit mode without saving.

---

## Delete a cancellation fee

<Steps>
  <Step title="Start deletion" icon="trash">

In **Existing Cancellation Fees**, select **Delete**.

  </Step>
  <Step title="Confirm deletion" icon="check-circle">

Campium asks **Are you sure you want to delete this cancellation fee session?** Select **Yes, delete**.

  </Step>
</Steps>

### When delete is blocked

You cannot delete a cancellation fee session that already has registrations. Its **Delete** button is grayed out. In that case:

- keep the existing session for historical records
- create a new one if you need a different amount/name going forward

---

## Recommended naming and setup

- Use one clear naming pattern each season (example: `Cancellation Fee - 2026`).
- Keep descriptions short and policy-focused.
- Avoid creating multiple sessions with nearly identical names.
- Confirm the amount with finance before saving.

---

## Troubleshooting

<ExpandableGroup>
  <Expandable title="Name is required">

Enter a **Name** and save again.

  </Expandable>
  <Expandable title="Amount must be greater than 0">

Enter an **Amount** greater than 0.

  </Expandable>
  <Expandable title="Description is required">

Enter a short **Description** and save again.

  </Expandable>
  <Expandable title="Session name already exists in this season">

Another session in this season already has that name. Use a different name, or edit the existing session instead of creating a duplicate.

  </Expandable>
  <Expandable title="Delete button does not work">

The session is already in use, and Campium shows **This cancellation fee session is in use and cannot be deleted.** Keep it and create a new cancellation fee session if needed.

  </Expandable>
</ExpandableGroup>

---

## Quick workflow checklist

- Open the right season
- Expand **Cancellation Fees**
- Create or edit with clear name/amount/description
- Save and verify it appears in **Existing Cancellation Fees**
- Delete only unused sessions
