## What note types are for

Note types are the categories your staff pick from when they add a note to a profile. Setting up clear note types (for example, "Behavior", "Health Follow-up", "Parent Call", or "Financial") keeps notes organized and makes them easier to find and report on later.

Note types are shared across your whole account. Everyone who can add a note to a profile chooses from the same list you manage here.

<Callout kind="info" collapsed="false">
  Note types organize the notes your team writes. They do not change who can see notes or what a note contains. They simply give each note a consistent category.
</Callout>

## Open the Note Types screen

<Steps>
  <Step title="Open the Admin menu" icon="settings" title-type="p">
    From the admin navigation, go to the **Admin** area.
  </Step>

  <Step title="Go to Note Types" icon="folder" title-type="p">
    Open **Note Types**. You see a table listing each note type by name, along with a **Usage** count showing how many notes currently use it.
  </Step>
</Steps>

## Add a note type

<Steps>
  <Step title="Start a new note type" icon="plus" title-type="p">
    Click **New Note Type** in the top right of the Note Types screen.
  </Step>

  <Step title="Name the note type" icon="edit" title-type="p">
    Enter a clear **Note Type Name** that describes the category. Short, consistent names work best because staff choose from this list every time they write a note.
  </Step>

  <Step title="Save the note type" icon="check-circle" title-type="p">
    Save your changes. The new note type appears in the list and is available the next time someone adds a note to a profile.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Agree on a short set of note types with your team before you create them. A focused list is easier to use consistently than a long one with overlapping categories.
</Callout>

## Edit a note type

Renaming a note type updates its label everywhere it is used.

<Steps>
  <Step title="Open the note type menu" icon="edit" title-type="p">
    In the Note Types list, use the menu icon at the start of the note type's row and choose **Edit**.
  </Step>

  <Step title="Update the name" icon="edit" title-type="p">
    Change the **Note Type Name** as needed.
  </Step>

  <Step title="Save the change" icon="check-circle" title-type="p">
    Save. The updated name applies to the note type across your account, including notes already tagged with it.
  </Step>
</Steps>

## Delete a note type

You can only delete a note type that is not in use.

<Steps>
  <Step title="Check the usage count" icon="search" title-type="p">
    In the Note Types list, look at the **Usage** column for the note type. The **Delete** option is only available when the count is zero, meaning no notes currently use that type.
  </Step>

  <Step title="Delete the note type" icon="trash" title-type="p">
    Use the menu icon on the note type's row and choose **Delete**. If the option is not shown, the note type is still attached to one or more notes.
  </Step>
</Steps>

<Callout kind="alert" collapsed="false">
  If a note type is already in use, you cannot delete it. Reassign or remove the notes that use it first, or simply keep the note type and rename it if the category has changed. This protects existing notes from losing their category.
</Callout>

## Tips for organizing note types

<Callout kind="tip" collapsed="false">
  - **Keep the list short**: A handful of clear categories is easier to apply consistently than a long list.

  - **Use plain language**: Name types the way your staff would describe the note out loud.

  - **Rename instead of duplicating**: If a category shifts, edit the existing note type rather than creating a near-duplicate.

  - **Review usage periodically**: The Usage column shows which types are actually being used and which you can retire.
</Callout>
