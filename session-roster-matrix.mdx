## Overview

Use the Session Roster Matrix to build a side-by-side grid of the campers enrolled in each session, so you can compare rosters across sessions at a glance. Pick a profile field and value (for example, Bunk and 5), then choose which sessions appear as columns. Each session column lists its enrolled campers sorted by first name.

## Build the grid

<Steps>
  <Step title="Choose a profile field" icon="filter" titleType="p">
    Select the profile field you want to filter by, such as Bunk, Group, or Age Group.
  </Step>

  <Step title="Choose a value" icon="check-circle" titleType="p">
    Pick the value for that field (for example, 5). Only campers matching this value appear in the grid.
  </Step>

  <Step title="Choose a season" icon="folder" titleType="p">
    Select the season whose sessions you want to compare.
  </Step>

  <Step title="Choose which sessions to show" icon="table" titleType="p">
    Open the Sessions dropdown to pick which sessions become columns. All sessions are selected by default; use the search box to filter and check or uncheck sessions.
  </Step>

  <Step title="Submit" icon="play" titleType="p">
    Select **Submit** to build the roster grid.
  </Step>
</Steps>

## Reading the grid

Each selected session becomes its own column, and each column lists the enrolled campers who match your filter, sorted by first name. Camper names link to their profiles. Because each column is filled independently, there are no gaps for campers who are not in a given session.

## Saved filters

Use the **Saved filters** controls to save a field, value, season, and session combination you use often. Save, rename, or delete a saved filter, then reload it later instead of rebuilding it each time.

## Where to find it

In Campium, go to **Reports** &gt; **System** and select the Session Roster Matrix.

## Troubleshooting

- **Grid is empty**: No enrolled campers match the chosen field and value for the selected sessions. Try a different value or add more sessions.
- **A session is missing as a column**: Open the Sessions dropdown and confirm that session is checked.
