## Overview

Use the Incorrect Age Report to find campers whose age does not line up with their date of birth, usually because the birth date is missing or entered incorrectly. A wrong birth date can throw off age-based grouping, eligibility, and pricing, so fixing these records keeps your data accurate.

<Callout kind="info">

This report lists active and pending campers whose birth date produces an age that looks wrong. It does not include filters or export options.

</Callout>

## Open the Incorrect Age Report

Access the report directly from the Data Check reports area.

<Steps>

  <Step title="Go to the Incorrect Age Report" icon="folder">

  - Sign in with an admin account.
  - In the main navigation, go to **Reports** and select **System**.
  - Under **Data Check**, choose **Incorrect Age**.
  - Confirm the page title reads `Incorrect Age`.

  When the page loads, you see a table with the columns **Name**, **Age**, and **Birth Date**. If nothing needs attention, the page reads `There are currently no incorrect ages.`

  </Step>

  <Step title="Correct each record" icon="check-circle">

  - Select a camper's **Name** to open the profile.
  - Compare the **Birth Date** on file against the correct date of birth and update it.
  - Save the profile; the camper drops off the report once the birth date and age agree.

  Make all changes from the profile. The report itself does not edit birth dates.

  </Step>

</Steps>

## Report columns

Each row is a camper whose birth date produces an age that looks incorrect.

### Name

Camper name, shown as a link. Select it to open the profile and correct the birth date.

### Age

The age calculated from the birth date on file. When this looks off, the birth date is usually the problem.

### Birth Date

The date of birth currently stored for the camper. This is the field to review and fix.

<Callout kind="alert">

Age drives grouping, eligibility, and pricing throughout your camp. Correct the birth date on the profile so the camper's age is accurate everywhere it is used.

</Callout>
